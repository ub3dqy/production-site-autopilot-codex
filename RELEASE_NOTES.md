# Production Site Autopilot v7.2.0-beta.1

This beta is a delivery and safety remediation release.

The canonical source, Skill, schemas, fixtures, tests, installers, CI, and release tooling are browsable in Git. Safety boundaries are backed by executable policy decisions. Mutation runs receive baselines, conflict-aware rollback, and versioned evidence reports.

Deterministic checks are run in CI. Live autonomous Codex evaluation and native Windows validation remain explicit evidence states; a stable release cannot silently accept `NOT_RUN`.

Release artifacts are generated from `VERSION` and include SHA-256 checksums, test evidence, an SBOM, and provenance metadata.
