# Production-ready profiles

## MARKETING_SITE

Build, routes, links, responsive layout, accessibility, metadata, sitemap/robots, forms, privacy/consent, security headers where applicable, and performance budgets.

## WEB_APPLICATION

Marketing gates plus authentication, authorization, sessions, API validation, migrations, secret handling, error reporting, backup/restore, and dependency security.

## COMMERCE

Web application gates plus payment boundaries, price/currency consistency, transactional messaging, returns, personal-data handling, and a prohibition on autonomous changes to commercial logic.

## REGULATED_OR_HIGH_RISK

Audit-only by default. Mutation requires a separately approved domain-specific policy; generic Autopilot policy is insufficient.
